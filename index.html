How to set it up

  1. Create a Google Sheet.
  2. In it: Extensions → Apps Script. Delete any code, paste the contents of apps-script/Code.gs.
  3. Get a free Groq key at console.groq.com/keys (optionally an OpenAI key at platform.openai.com/api-keys for fallback).
  4. In Apps Script: Project Settings (⚙) → Script Properties → add GROQ_API_KEY = your key (and OPENAI_API_KEY for fallback).
  5. Deploy → New deployment → Web app. Execute as Me, access Anyone. Copy the /exec URL.
  6. Paste that URL above and press Test connection.
Optional: archive card photos to Drive

Add a Script Property DRIVE_FOLDER_ID with a Drive folder ID, and each saved card image is stored there with a link in the sheet.

Safety

The AI is instructed to ignore credit-card number, CVV and expiry — those are never read or stored. Keep the sheet private; it holds donor personal information.
